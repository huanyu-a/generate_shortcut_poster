  这个Python脚本的功能是创建一个Windows快捷键大全的海报图片，具有以下特点：

  🎨 脚本功能概览

  📋 主要特性：
   - 分辨率：1920x1080（全高清）
   - 背景：深蓝色渐变背景（#0A0E27）
   - 布局：6个功能区域，每个区域有不同的颜色主题
   - 字体：使用Windows系统免费字体（微软雅黑、黑体、宋体）

  🎯 六个功能区域：
   1. 🏠 通用快捷键（青色）- Win键组合、Alt+Tab等
   2. 🖥️ 窗口管理（蓝色）- 窗口分屏、虚拟桌面等
   3. 🎮 游戏与截图（绿色）- Xbox Game Bar、截图快捷键
   4. ⚙️ 系统命令（紫色）- cmd、任务管理器等运行命令
   5. 📁 文件资源管理器（黄色）- 文件操作快捷键
   6. ♿ 辅助功能（粉色）- 放大镜、屏幕键盘等

  🔧 技术实现：
   - 使用PIL库进行图像处理
   - 支持圆角矩形、半透明背景效果
   - 自动计算文字宽度和居中
   - 生成专业的海报效果

  💾 输出文件：
   - 保存路径：output/windows_shortcuts_poster_final.png
   - 文件格式：PNG（保持透明度）
